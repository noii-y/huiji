灰迹是一款 Windows 拼音输入法，做给「想在工作里顺便学点外语、又挤不出整块时间」的人。

你每天要写邮件、改文档、回消息，在键盘上敲下成千上万次。灰迹把外文放进这个过程里：候选词旁边跟着这个词的外文和词性，一整句敲完，还能看到整句话怎么讲。不用另开学习软件，也不用专门腾出时间，打字时眼睛顺带扫过去，日子久了，词就记住了。

它从开源输入法 [青简](https://github.com/qingjian-team/qingjian) 长出来。青简「打字时顺便认识一个词」的想法和最难的地基，灰迹都接了过来，又把学习从「词」扩到「句」。

## 为什么叫灰迹

输入法本该待在后台，你打字时几乎察觉不到它——这是「灰」，克制，不抢戏。

哪些词从陌生看到熟、你嘴上常挂什么话、改过哪些手误，这些都会留下痕迹，外语和输入法一起，慢慢变成「你的」——这是「迹」。

样子也照着这个脾气。默认是一套深色的「石墨深邃」皮肤：深灰底、圆角、首选词左边一道暖琥珀竖条，在一片灰里给一点提示。图标是透明底的「灰」字，默认深色，不跟随系统。

## 边打字，边学外语

<p align="center">
  <img src="huiji/assets/huiji-candidates.png" alt="灰迹候选窗" width="380">
</p>

- **词旁边就是外文。** 选词时眼睛顺带扫一眼：这个词英文怎么拼、是动词还是名词。一天敲几千字，就多看几千眼，比正襟危坐背单词轻松，也更容易坚持。这套「词旁译词」是青简的招牌，灰迹原样保留。
- **生词会提醒，熟了就退场。** 没见过几次的词标成橙色，提醒你多留意；看多了、记住了，自动变回普通灰色，不会一直分你的神。
- **整句敲完，看整句怎么说。** 这是灰迹加上去的：想知道一整句话英文怎么讲，不必逐词凑，连续敲完拼音，候选窗顶部直接给整句，比如敲 `nijintianwanshangyoukongma` 给出 `Are you free tonight?`（见上图）。模型在本机、离线，约 81 MB，随安装包装好，100 句测试里译文延迟中位数 50 毫秒。流行语也单独照顾，「摸鱼」是 slack off、「内卷」是 rat race，比直译像话。
- **英语、日语都能选**，一次学一种，日语按汉字标假名。

## 输入法本身，也得顺手

学习是顺便的，前提是打字不被打扰。地基的活灰迹没含糊：

- 整句输入，候选由本机小模型重排，全拼、简拼、双拼、模糊音都支持；
- 手滑和缩写：默认开「中文优先」，声母缩写的首选命中率从 66.2% 提到 77.5%；
- 键位对齐微软拼音：`-`/`=` 翻页（小键盘 `+`/`-` 也行）、`Ctrl+.` 切中英标点、`Ctrl+Shift+F` 切简繁、`Shift+空格` 切全半角、V 模式算算式和查日期时间；
- 游戏检测到独占全屏就整体让位，不吃键、不弹窗、不卡死，能正常 Alt+Tab；
- 另有拼写纠错、英文模式、emoji；云联想默认关闭。

## 站在青简的肩膀上

青简是一个用 Rust 写的拼音输入法，本地优先，整句候选由本机小模型重排。灰迹基于它（GPL-3.0-or-later）开发，保留了完整提交历史，随时可以溯源，也守住了「输入不被翻译拖慢、一切全在本机」的架构。它也有 macOS、Linux 的外壳，灰迹目前只在 Windows 上打磨，那两份代码还在，但没专门调过。

青简的作者和社区做了最难的地基，在此致敬。按 GPL 的要求，灰迹同样以 GPL-3.0-or-later 开源。随包数据各有来源与许可，见 [docs/design/landscape.md](docs/design/landscape.md)。

## 安装

到 [Releases](https://github.com/noii-y/huiji/releases) 下载最新的 `huiji-<版本>-windows-x86_64-setup.exe`，双击安装，按提示注销或重启一次。安装包约 125 MB，翻译模型和运行时都打在里面，装完离线就能用，不用再单独下载。安装需要管理员授权，在 UAC 弹窗点「是」。

想从源码编译，见 [apps/windows/README.md](apps/windows/README.md)。

## 数据与隐私

拼音转换、词库、翻译、学习都在本机完成，不需要账号。云联想和云端翻译默认关闭，只有你自己填入 AI 服务商的 key 之后才会发请求，而且请求直接发给服务商、不经过灰迹。

## 当前状态与路线图

灰迹目前聚焦 Windows：词旁译词、生词提醒、端侧整句译文都已在真机闭环，键位对齐了微软拼音，游戏全屏不再卡死。云端整句翻译的链路也已就绪，填入 OpenAI 兼容的 key（DeepSeek 等）就能给长难句兜底。

还在排队的：游戏全屏下的中文输入、端侧整句语言模型、云端结果的本地记忆、U 模式（笔划/部件）。一步步的进展写在 [开发日志](huiji/开发日志.md) 里。
