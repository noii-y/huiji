灰迹是一款 Windows 拼音输入法，做给「想在工作里顺便学点外语、又挤不出整块时间」的人。

你每天要写邮件、改文档、回消息，在键盘上敲下成千上万次。灰迹把外文放进这个过程里：候选词旁边跟着这个词的外文和词性，一整句敲完，还能看到整句话怎么讲。不用另开学习软件，也不用专门腾出时间，打字时眼睛顺带扫过去，日子久了，词就记住了。

灰迹继承自开源输入法 [青简](https://github.com/qingjian-team/qingjian)。青简「打字时顺便认识一个词」的理念与核心基础，灰迹均予以继承，并把学习范围从「词」扩展到「句」，也重做了候选排序和游戏兼容。

## 为什么叫灰迹

输入法本该待在后台，你打字时几乎察觉不到它——这是「灰」，克制，不抢戏。

哪些词从陌生看到熟、你嘴上常挂什么话、改过哪些手误，这些都会留下痕迹，外语和输入法一起，慢慢变成「你的」——这是「迹」。

视觉也照着这个思路。默认是深色的「石墨深邃」皮肤：深灰底色、圆角，首选词左侧有一道暖琥珀竖条，在一片灰里给出提示。图标是透明底的「灰」字，默认深色，不跟随系统。

## 边打字，边学外语

  <img src="https://github.com/noii-y/huiji/raw/main/huiji/assets/huiji-candidates.png" alt="灰迹候选窗" width="380">
</p>

- **词旁边就是外文。** 选词时顺带扫一眼：这个词英文怎么拼、是动词还是名词。一天敲下几千字，就反复见了这些词几遍，比正襟危坐背单词轻松，也更容易坚持。这套「词旁译词」是青简的标志性功能，灰迹原样保留。
- **生词会提醒，熟后不再标注。** 不常见的词标成橙色，提示多留意；见得多了自动恢复普通灰色，不一直分散注意力。
- **整句敲完，看整句怎么讲。** 这是灰迹新增的能力：连续敲完一句拼音，候选窗顶部就给出整句译文，不用逐词去拼。例如敲 `nijintianwanshangyoukongma` 会得到 `Are you free tonight?`。翻译在本机运行、完全离线，随安装包装好，不卡顿、不用联网。网络流行语也译得地道，「摸鱼」是 slack off、「内卷」是 rat race，不是生硬直译。
- **英语、日语都能选**，一次学一种，日语按汉字标假名。

## 打字本身，也得靠谱

学习是顺便完成的，前提是打字不被打扰。灰迹在基础输入上下了不少功夫：

- **首选词就是正常人会讲的话。** 词频基于真实使用频率，多音字按常见读音优先，生僻读音、别扭的叠字和搭配会自动靠后，不会冒出没人这么讲的组合。日常打字，首选基本就是你想要的那句。
- **全拼、简拼、缩写、模糊音都支持。** 默认中文优先，打首字母、缩写也能直接给出中文词；打 `Linux`、`Google` 这类拉丁专有名词，也会直接给规范写法。
- **键位对齐微软拼音**：`-`/`=` 翻页（小键盘 `+`/`-` 也行）、`Ctrl+.` 切中英标点、`Ctrl+Shift+F` 切简繁、`Shift+空格` 切全半角、V 模式算算式和查日期时间。
- **游戏里不捣乱。** 检测到独占全屏就整体让位：不拦按键、不弹窗、不卡顿，Alt+Tab 正常，全屏游戏里也能打中文。
- 另有拼写纠错、英文模式、emoji。

## 云端：手误也能还原成本意

本地统计能处理大部分情况，但遇到手误、漏字母、一串拼音打拧了，它未必猜得准。这时可以开云端纠错：把当前拼音发给一个大模型，让它还原你本来想打的那句中文。

比如手滑漏了字母、把 `womintianxiangxiuxi` 打出去，云端会单独给出一行「我明天想休息」，按 Tab 就上屏。它只做纠错还原，不扩写、不接下文；如果本地首选已经够好，这一行就不出现。

云端默认关闭，需要你自己填一个兼容 OpenAI 接口的 key（DeepSeek 等）。钱是小头：以 DeepSeek Flash 为例，日常打字量每月大约 1～3 元（**测算**，按实际调用量浮动）。密码框等私密字段、文件管理器不会发请求；断网或报错就安静退回本地，不影响打字。

## 设置与 API 密钥

灰迹有统一的设置界面，从开始菜单「灰迹 → 灰迹设置」打开，也可以在输入法上右键选「设置」。里面分常规、候选、快捷键、模糊音、词典、辅码、云服务、高级等几页，主题、候选数、翻页键、学习语言、模糊音、自启更新都能改，改完即时生效。

**接云端（填自己的 key）**：

1. 打开「灰迹设置」，进「云服务」页；
2. 打开「启用云联想」；
3. 填接口地址（DeepSeek 为 `https://api.deepseek.com`）、模型名（`deepseek-flash`）和 API 密钥；
4. 点「测试连接」确认能通。

密钥只存在这台电脑上，不回显、不随配置导出，也不会打进安装包；开源项目每人用自己的 key，不共用。习惯用配置文件或环境变量的进阶用户，可直接编辑本机配置，字段与界面一致。

语言栏右键还有「退出灰迹」，确认后切回 Windows 默认输入法（如微软拼音），不会卡死。

## 与青简的关系

青简是一款用 Rust 开发的拼音输入法，本地优先，候选在本机生成、不依赖云端。灰迹基于青简（GPL-3.0-or-later）开发，保留了完整提交历史，可随时溯源，也守住「输入不被翻译拖慢、能在本机完成的都在本机完成」这条架构。青简另有 macOS、Linux 实现，灰迹目前只专注 Windows，这两部分代码保留、未专门适配。

感谢青简的作者和社区打下最核心的基础。按 GPL 要求，灰迹同样以 GPL-3.0-or-later 开源。随包数据各有来源与许可，详见 [docs/design/landscape.md](docs/design/landscape.md)。

## 安装

前往 [Releases](https://github.com/noii-y/huiji/releases) 下载最新的 `huiji-<版本>-windows-x86_64-setup.exe`，双击运行，按提示注销或重启一次。翻译模型和运行时都已集成，装完即可离线使用，无需另下；安装需要管理员授权，在 UAC 弹窗选「是」。

从源码编译的说明见 [apps/windows/README.md](apps/windows/README.md)。

## 数据与隐私

拼音转换、词库、翻译、学习都在本机完成，不需要账号。云联想默认关闭，只有你自己填入 key 之后才发请求，请求直接发给服务商、不经过灰迹。个人学习数据留在本机，文件管理器等场景默认不记录。

## 当前状态与路线图

Windows 上词旁译词、生词提醒、整句译文、云端纠错都已可用，键位对齐微软拼音，全屏游戏能正常打字、不再卡死。

往后想做的：更多语种的整句译文、U 模式（笔划 / 部件查字）、云端结果的本地记忆、macOS / Linux 适配。各阶段过程见 [开发日志](huiji/开发日志.md)。
