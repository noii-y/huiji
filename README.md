灰迹是一款 Windows 拼音输入法，做给「想在工作里顺便学点外语、又挤不出整块时间」的人。

你每天要写邮件、改文档、回消息，在键盘上敲下成千上万次。灰迹把外文放进这个过程里：候选词旁边跟着这个词的外文和词性，一整句敲完，还能看到整句话怎么讲。不用另开学习软件，也不用专门腾出时间，打字时眼睛顺带扫过去，日子久了，词就记住了。

灰迹继承自开源输入法 [青简](https://github.com/qingjian-team/qingjian)。青简「打字时顺便认识一个词」的理念与核心基础，灰迹均予以继承，并将学习范围从「词」扩展至「句」。

## 为什么叫灰迹

输入法本该待在后台，你打字时几乎察觉不到它——这是「灰」，克制，不抢戏。

哪些词从陌生看到熟、你嘴上常挂什么话、改过哪些手误，这些都会留下痕迹，外语和输入法一起，慢慢变成「你的」——这是「迹」。

视觉设计也遵循这一理念。默认提供深色的「石墨深邃」皮肤：深灰底色、圆角，首选词左侧有一道暖琥珀竖条，在整体灰色中给出提示。图标为透明底的「灰」字，默认深色，不跟随系统。

## 边打字，边学外语

- **词旁边就是外文。** 选词时眼睛顺带扫一眼：这个词英文如何拼写、是动词还是名词。一天敲下数千字，便能反复接触这些词，比正襟危坐背单词轻松，也更容易坚持。这套「词旁译词」是青简的标志性功能，灰迹原样保留。
- **生词会提醒，熟后不再标注。** 不常见的词标为橙色，提示多加留意；多次出现并记住后，自动恢复为普通灰色，不会持续分散注意力。
- **整句敲完，看整句如何表达。** 这是灰迹新增的能力：想了解一整句话的英文表达，不必逐词拼接，连续敲完拼音，候选窗顶部即给出整句译文，例如敲 `nijintianwanshangyoukongma` 会得到 `Are you free tonight?`（见上图）。模型运行于本机、完全离线，约 81 MB，随安装包一并安装；在 100 句测试中，译文延迟中位数为 50 毫秒。流行语也做了单独处理，「摸鱼」译为 slack off、「内卷」译为 rat race，比直译更符合表达习惯。
- **英语、日语都能选**，一次学一种，日语按汉字标假名。

## 输入法本身，也得顺手

学习是顺便完成的，前提是打字过程不被打扰。基础能力方面，灰迹同样扎实：

- 整句输入，候选由本机小模型重排，全拼、简拼、双拼、模糊音都支持；
- 误输入与缩写：默认开启「中文优先」，声母缩写的首选命中率从 66.2% 提升至 77.5%；
- 键位对齐微软拼音：`-`/`=` 翻页（小键盘 `+`/`-` 也行）、`Ctrl+.` 切中英标点、`Ctrl+Shift+F` 切简繁、`Shift+空格` 切全半角、V 模式算算式和查日期时间；
- 检测到游戏独占全屏时自动停用，不拦截按键、不弹出窗口、不造成卡顿，并可正常 Alt+Tab；
- 另有拼写纠错、英文模式、emoji；云联想默认关闭。

## 与青简的关系

青简是一款使用 Rust 开发的拼音输入法，本地优先，整句候选由本机小模型重排。灰迹基于青简（GPL-3.0-or-later）开发，保留了完整提交历史，可随时溯源，同时遵循「输入不被翻译拖慢、一切处理均在本机完成」的架构。青简也提供 macOS、Linux 的实现，灰迹目前仅专注于 Windows 平台，这两部分代码予以保留，但未做专门适配。

青简的作者与社区奠定了最核心的基础，在此致以敬意。依据 GPL 许可要求，灰迹同样以 GPL-3.0-or-later 开源。随包数据各有其来源与许可，详见 [docs/design/landscape.md](docs/design/landscape.md)。

## 安装

前往 [Releases](https://github.com/noii-y/huiji/releases) 下载最新的 `huiji-<版本>-windows-x86_64-setup.exe`，双击运行安装，并按提示注销或重启一次。安装包约 125 MB，翻译模型与运行时均已集成其中，安装后即可离线使用，无需另行下载。安装需要管理员授权，请在 UAC 弹窗中选择「是」。

如需从源码编译，请参阅 [apps/windows/README.md](apps/windows/README.md)。

## 数据与隐私

拼音转换、词库、翻译、学习都在本机完成，不需要账号。云联想和云端翻译默认关闭，只有你自己填入 AI 服务商的 key 之后才会发请求，而且请求直接发给服务商、不经过灰迹。

## 当前状态与路线图

灰迹目前聚焦 Windows：词旁译词、生词提醒、端侧整句译文均已在真机环境验证通过，键位对齐微软拼音，游戏全屏不再卡死。云端整句翻译的链路也已就绪，填入 OpenAI 兼容的 key（DeepSeek 等）即可为长难句提供补充。

计划中的功能：游戏全屏下的中文输入、端侧整句语言模型、云端结果的本地记忆、U 模式（笔划/部件）。各阶段进展记录于 [开发日志](huiji/开发日志.md)。
