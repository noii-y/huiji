# 灰迹输入法发版 SOP（Windows）

适用范围：Windows 端从「干净全新安装」到「物理键盘真机回归」的完整发版前检查清单。
自动化前置：跑 `huiji/评测/release-gate.ps1`（三道门禁：全量单测 / 自造锁定集首选率 / 真实语料采样基线），输出 `RELEASE GATE: PASS` 后才进入本 SOP。本 SOP 里凡是标注 **[真机/重启]** 的步骤，都必须由 PM 或用户在真实机器上执行——脚本与开发环境不代做真机操作。

日志位置（所有预期日志均在此目录）：`%LOCALAPPDATA%\Qingjian\logs\`，按天分文件留 7 天：
`server.<日期>.log`（Engine / 云 / 端侧翻译）、`tsf.<日期>.log`（DLL 按键与候选窗锚点）、`settings.<日期>.log`。

---

## 阶段 A：干净全新安装

| # | 步骤 | 验证方法 | 预期结果 |
| --- | --- | --- | --- |
| A1 | 卸载旧版灰迹 | Windows「设置 → 应用」卸载当前安装包；或跑安装目录里的 Uninstall | 卸载向导走完，无报错弹窗 |
| A2 | 清理旧 Server 进程 | 任务管理器「详细信息」页找 `qingjian-server.exe` | 不存在；若有则结束它 |
| A3 | 反注册旧 DLL（有旧注册时） | 管理员 PowerShell：`regsvr32 /u "<安装目录>\qingjian_tsf.dll"` | 提示反注册成功 |
| A4 | 安装当前版本包 | 运行 Inno 安装包（管理员），按默认路径装完 | 安装目录含 `qingjian-server.exe`、`qingjian_tsf.dll`、设置程序与随包数据；无缺文件报错 |
| A5 | [真机/重启] 重启 Windows | 重启一次（注销重登亦可，推荐完整重启） | 让 TSF 注册与 uiAccess 清单在干净会话里生效 |

## 阶段 B：重启后首次开机检查 **[真机/重启]**

| # | 步骤 | 验证方法 | 预期结果 |
| --- | --- | --- | --- |
| B1 | 单 Server 进程 | 切出灰迹敲几个字后，任务管理器查 `qingjian-server.exe` | 全系统只有 **1 个** `qingjian-server.exe`；多个即 FAIL，看 `server.<日期>.log` 是否有重复启动 |
| B2 | 旧 DLL 全部消失 | 任务管理器任意带输入框进程（如 Notepad）属性→已加载模块搜 `qingjian_tsf.dll`；安装目录无旧版残留 dll | 加载的是新装目录里的新版 dll；仓库/旧目录里的旧 dll 无加载痕迹 |
| B3 | 日志冷启动正常 | 打开当天 `server.<日期>.log` | 有「加载完成 dict=…」「Engine 就绪 total_ms=…」，无 `unknown variant`、无 panic、无重复启动段 |

## 阶段 C：物理键盘逐项回归 **[真机/重启]**

每一项：在任意输入框（推荐 Notepad 与一个微信聊天窗各过一遍）敲指定按键，对照预期结果打勾。

| # | 检查项 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| C1 | Ctrl+空格英文直通 | 中文态直接按 `Ctrl+空格`；再在组句过程中（拼音已上屏一半时）按 `Ctrl+空格` | ① 直通切英文，敲字母直接上屏、不组句；② 组句中途切英文时，已经敲下的原始字母原样上屏，不丢字、不改成中文；切回后状态正确 |
| C2 | Tab 云提示在首位且外文跟随 | 中文态在 Notepad 敲 `wojintianqugongyuan`，停手不按键约 0.5 秒，然后：① 看一眼候选区；② 按一次 `Tab`；③ 按空格；④ 复现一次（重新组句后先不按 Tab，按 `Esc`） | ① 本地候选照常实时出，不等云；② 约 300ms 后出现云整句；③ 第一次按 `Tab` 云整句被选为首位（高亮成首位候选）但**不上屏**，拼音行右侧顶部外文同步切到云译文；④ 按空格（或回车）上屏的是云整句；⑤ 云整句在首位时按 `Esc` 只取消选中，云整句回到待选、拼音与本地候选不清空。确认日志：启动行 `云端拼音纠错已接入 model = deepseek-flash`，且无 `云端纠错接入失败` |
| C3 | 大写分段 | 分别敲 `Cpan`（首字母大写）与全小写 `cpan`，各看上屏结果 | 两边都出候选「C盘」（匹配按小写算）；拼音行保留敲入的 `Cpan` 形状（`C` 不大写化进拼音音节、`pan` 不被读成别的）；回车/直接上屏还原成大写 C，不出 `c盘` |
| C4 | `-` `=` 翻页边界 | 候选多页时连续按 `=` 翻到最后一页，再按 `=`；再按 `-` 翻回第一页后继续按 `-` | 到边界后停住（不循环、不闪退、候选窗不消失）；往回翻同样到首页停住；翻页浏览本地候选时云整句退出首位 |
| C5 | 拉丁专有名词 | 敲 `womaileyigeiphone`、`yongdockerbushuhenfangbian` | 拉丁串 `iphone`/`docker` 按字母原样上屏（`iphone` 保持小写 i 不大写），不被硬读成拼音音节（不出「用的哦乘客」这类废话）；可正常选词修正 |
| C6 | 长句译文不漏词 | 敲 `yishengdangjiquezhenweiyupuchangbujiemanchongyinqideguomin`（对应原句「医生当即确诊为由于床铺不洁螨虫引起的过敏」，20 字），停手等云整句 | 云整句覆盖全部 20 字、与原句逐字一致（此句本地统计易错成「党籍/不接/国民」类错词，云应全对）；上屏后拼音行右侧外文译文完整、不漏词、不截断。确认日志：启动行 `端侧整句翻译已接入（离线）` 在 |
| C7 | 断网时 opus-mt 兜底 | 断网（拔网线/关 Wi-Fi）后重复 C2 组句 | 云请求超时静默回退：本地首选照常出；译文仍由端侧 opus-mt（本地 CT2）给出，不卡死、不弹错；`server` 日志有云超时/回退记录 |
| C8 | 游戏全屏 | 全屏运行一个不实现真文本 store 的全屏程序（如 Dota2 类），在其中唤起灰迹组句 | 候选窗跟随鼠标，不被钉在屏幕外角落；`tsf` 日志出现「GetTextExt 返回屏幕外矩形 (…,…)，退回鼠标定位」 |
| C9 | 退出灰迹不卡死 | 退出 Server / 注销输入法后，在 Notepad 连续敲字 | 宿主进程不卡死、不空白、不连锁崩溃；旧 DLL 卸载干净 |
| C10 | 单 Server 进程与旧 dll 复查 | 跑完 C1–C9 后回查 B1/B2 | 全程仍只有 1 个 `qingjian-server.exe`；无旧版 dll 被任何进程加载 |

## 收尾

1. C 类任一项 FAIL：记现象、操作步骤、系统版本、当天 `server/tsf` 日志，按 bug 流程提 issue（真机现象必须留证，编译通过不算验证）。
2. 全部 PASS：日志目录打包留档，发版负责人在发版记录里登记「release-gate PASS + SOP A–C 全项通过 + 执行人/日期」。
3. 本清单不含：push / Release 标签、打包签名、UAC 清理自动化——那些属发版负责人另行操作。
